# Short-Term Bitcoin Trend Prediction Using Machine Learning

## Project Description

This project is a Machine Learning system that predicts the short-term trend of Bitcoin price.

The system predicts whether the Bitcoin price will go:

- UP
- DOWN

The project is created for educational purposes and demonstrates Machine Learning System Design.

## Problem Statement

Bitcoin is a highly volatile asset. Traders and analysts often need tools to understand short-term market direction.

This project uses historical Bitcoin market data to predict whether the price will increase or decrease on the next day.

## Dataset

The dataset is collected from Yahoo Finance using the `yfinance` Python library.
